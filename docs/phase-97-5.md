# Phase 97.5 — Schémas des bases et guide des migrations

Le [résumé des schémas PostgreSQL](database-schemas.md) cartographie les huit bases, leurs tables principales, leurs ports Compose loopback et l'état actuel des migrations. Le [guide EF Core](migrations.md) décrit une procédure de revue et les commandes par `DbContext`, y compris la production d'un script idempotent.

Validation documentaire : les contextes, snapshots, répertoires de migration et ports Compose ont été inventoriés dans le dépôt. Aucune base persistante n'a été démarrée, sauvegardée ou migrée ; aucune migration n'a été créée.
